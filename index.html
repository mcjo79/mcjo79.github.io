Project 01 · 2026

VRoid MCP Bridge

A local MCP bridge that lets Claude Code, Claude Desktop, DeepSeek or any MCP client drive VRoid Studio: 34 tools for parameters, textures, hair, presets, camera and captures. Every edit goes through VRoid’s own history, so Ctrl+Z works.
